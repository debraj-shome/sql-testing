# SQL Testing Portfolio

## Overview

This repository contains SQL queries and database testing examples created as part of my QA and Software Testing portfolio.

The purpose of this repository is to demonstrate practical SQL knowledge used by QA Engineers for:

- Database validation
- Data verification
- Backend testing
- CRUD validation
- Data integrity testing
- API response validation
- Functional testing
- Defect investigation

## SQL Skills Covered

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- DISTINCT
- LIKE
- BETWEEN
- IN
- IS NULL
- INSERT
- UPDATE
- DELETE
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Aggregate Functions
- Subqueries
- CASE statements
- Data validation
- Duplicate data detection
- NULL value validation
- Referential integrity validation
